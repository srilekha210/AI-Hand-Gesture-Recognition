# AI Hand Gesture Recognition

## Project Overview

This project is an AI-based hand gesture recognition system
developed using Python, OpenCV and MediaPipe.

The system uses a webcam to detect hand landmarks and
recognize basic hand gestures in real time.

## Gestures Recognized

- Open Hand
- Fist
- Thumbs Up
- Victory / Peace

## Technologies Used

- Python
- OpenCV
- MediaPipe

## Features

- Real-time webcam detection
- Hand landmark detection
- Gesture classification
- Live gesture display

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the project:

python gesture_recognition.py

Press Q to exit the application.

## Project Purpose

The purpose of this project is to demonstrate an AI-based
computer vision application that recognizes basic hand
gestures using real-time webcam input.
